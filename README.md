# Phone Prices Worldwide feedback

Public price corrections for [Phone Prices Worldwide](https://iphonepricesworldwide.com/), maintained by [Rahul Singh](https://github.com/rahul-singh-au9).

[Report a price correction](https://github.com/rahul-singh-au9/phone-prices-worldwide-feedback/issues/new?template=price-correction.yml) with the model, configuration, country, official store link, observed price and the date you checked it. Reporting requires a GitHub account, and reports and replies are public. Include only public store information, without account details or receipts.

Reports are checked against the official source for the same configuration. Confirmed errors are corrected in a subsequent catalogue publication. A changed store price becomes a new dated observation; an unverified report does not replace existing evidence.

Read the [sources and methodology](https://iphonepricesworldwide.com/methodology#corrections) for the comparison rules, tax treatment and freshness limits.
